An entry for the [make.fun](https://make.fun) bounty
"Sum up 24 November's world news in one image".

`main.py` draws a deterministic 1024x1024 newspaper front page — pure
Python standard library, no network, no installed packages — and writes it
to `/output/entry.png`. The image is byte-identical on every run.

5. **Waymo pulls driverless taxis off freeways** — the robotaxi firm
   suspends freeway trips after California's ban and traffic incidents.
6. **Eisenkot calls settler arson "Jewish terrorism"** — the Israeli

7. **Migrant boat sinks off Senegal, dozens missing** — rescuers search for

8. **Gaza contamination report** — Oxfam and CEOBS warn explosive residues

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
